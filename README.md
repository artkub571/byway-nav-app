# Byway Nav for Android

Motorcycle navigation for UK green lanes: legal byways and unclassified roads from council rights-of-way data, offline maps, offline routing, ride recording.

This repository only holds the app's releases. Download the latest `.apk` from **Releases**.

## Installing

1. On your Android phone or tablet, download the `.apk` from the latest release.
2. Open it. The first time, Android asks you to allow installing apps from your browser or file manager: allow it.
3. In the app, open **Offline maps** on Wi-Fi to download the map and routing data for Great Britain (about 1.6 GB; the SD card is fine).

Updates: the app checks this page on Wi-Fi (Settings → App updates) and asks you to tap Install. Your routes, rides and settings are kept.

## Route packs

The Trans Euro Trail (TET), ACT and TRF route files are **not** included: their publishers allow personal use only. Download them from their publishers and import them (GPX library → Import): the app recognises them, puts each section in its own collection and colours them like the rest.
